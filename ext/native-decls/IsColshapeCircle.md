## IS_COLSHAPE_CIRCLE

```c
BOOL IS_COLSHAPE_CIRCLE(int colShapeId);
```

Returns whether the collision shape with the given ID is a circle.

## Parameters
* **colShapeId**: The collision shape ID.

## Return value
Returns true if the collision shape exists and is a circle, false otherwise.
