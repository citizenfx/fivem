## IS_COLSHAPE_SPHERE

```c
BOOL IS_COLSHAPE_SPHERE(int colShapeId);
```

Returns whether the collision shape with the given ID is a sphere.

## Parameters
* **colShapeId**: The collision shape ID.

## Return value
Returns true if the collision shape exists and is a sphere, false otherwise.
