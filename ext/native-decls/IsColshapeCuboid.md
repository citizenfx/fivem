## IS_COLSHAPE_CUBOID

```c
BOOL IS_COLSHAPE_CUBOID(int colShapeId);
```

Returns whether the collision shape with the given ID is a cuboid.

## Parameters
* **colShapeId**: The collision shape ID.

## Return value
Returns true if the collision shape exists and is a cuboid, false otherwise.
