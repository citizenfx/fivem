## IS_COLSHAPE_RECTANGLE

```c
BOOL IS_COLSHAPE_RECTANGLE(int colShapeId);
```

Returns whether the collision shape with the given ID is a rectangle.

## Parameters
* **colShapeId**: The collision shape ID.

## Return value
Returns true if the collision shape exists and is a rectangle, false otherwise.
