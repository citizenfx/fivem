## IS_COLSHAPE_CYLINDER

```c
BOOL IS_COLSHAPE_CYLINDER(int colShapeId);
```

Returns whether the collision shape with the given ID is a cylinder.

## Parameters
* **colShapeId**: The collision shape ID.

## Return value
Returns true if the collision shape exists and is a cylinder, false otherwise.
